# Glossary

- **Site**: the Go application serving jamesakent.com (not the REPL).
- **REPL**: the existing biff-repl Clojure app, served at `/repl`.
- **Project**: see `entities.md`.
- **Demo**: a project that runs live in the browser, hosted on a subdomain.
- **Visitor**: anyone using the public site, human or agent.
- **Stack**: Caddy, the site, biff-repl and Jaeger, run together by `make up`.
- **Profile**: see `entities.md`.
- **About page**: the page that presents the profile.
